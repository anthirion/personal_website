# Personal website

Mon site web est un simple blog dont l'objectif est de partager à travers de courts articles mes expérimentations sur plusieurs technologies, en fonction de mes envies. Il est construit avec Django et PostgreSQL et est hébergé sur Azure.

## Rappels des principales commandes Django

1. Lancer un projet dans le répertoire courant et créer tous les dossiers et fichiers nécessaires :

```bash
django-admin startproject <my_project> .
```

2. Lancer le serveur web Django :

```bash
python manage.py runserver
```

3. Lancer une app et créer tous les dossiers et fichiers nécessaires :

```bash
python manage.py startapp <my_app>
```
